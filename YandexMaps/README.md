# Библиотека `YandexMaps`

Библиотека для `1С:Предприятие.Элемент`, которая добавляет интерактивную карту Яндекс Карт в виде переиспользуемого компонента интерфейса.

## Что входит

- публичная структура `korolevpavel::YandexMaps::Основное::МеткаКарты`
- публичный компонент `korolevpavel::YandexMaps::Основное::КартаЯндекса`
- настройки библиотеки `korolevpavel::YandexMaps::Настройки::НастройкиYandexMaps`

Библиотека не навязывает проекту-потребителю свою модель хранения локаций. Метки можно хранить в собственных объектах приложения и передавать в карту как `Массив<МеткаКарты>`.

## Подключение

1. Добавьте библиотеку в состав зависимостей приложения.
2. Откройте настройки `korolevpavel::YandexMaps::Настройки::НастройкиYandexMaps.СоздатьФормуЗаписи().Открыть()`.
3. Заполните `ApiKey`.
4. Ограничьте ключ в кабинете Яндекс Карт по домену приложения.

## Использование в форме

```yaml
Импорт:
    - korolevpavel::YandexMaps::Основное
```

```yaml
-
    Тип: КартаЯндекса
    Имя: КартаСобытий
    Метки: =МеткиКарты
    АвтоПодобратьГраницы: Истина
    КластеризоватьМетки: Истина
```

## Формирование массива меток

```xbsl
пер МеткиКарты = новый Массив<МеткаКарты>()

МеткиКарты.Добавить(
    новый МеткаКарты(
        Идентификатор = "equium-loft",
        Широта = 59.960000,
        Долгота = 30.320000,
        Заголовок = "Эквиум Лофт",
        Описание = "Санкт-Петербург, ул. Малая Посадская 7/4, 2 этаж"
    )
)
```

## Рекомендации по интеграции

- храните бизнес-данные о локациях в собственных объектах приложения
- преобразуйте их в `Массив<МеткаКарты>` в прикладном коде
- используйте `ApiKey` свойства компонента только как override для нестандартных сценариев
- основной способ хранения ключа: `НастройкиYandexMaps.ApiKey` типа `СекретПриложения`

## Ограничения v1

- компонент только отображает карту и стандартные balloon/hint
- геокодирование адресов библиотека не выполняет
- выбор координаты мышью и встроенный редактор меток не реализованы
- ключ безопасно хранится в настройках приложения, но при использовании JS API все равно участвует в клиентской загрузке скрипта
