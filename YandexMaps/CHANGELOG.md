# Changelog

## 1.0.3

- компонент `КартаЯндекса` не задаёт размер по умолчанию — нейтральный по отношению к лейауту
- размер задаётся на каждом инстансе через встроенные свойства платформы: `Высота`, `Ширина`, `РастягиватьПоВертикали`, `РастягиватьПоГоризонтали`
- ⚠️ Breaking change: ранее компонент растягивался по умолчанию; теперь нужно задавать размер явно на инстансе

## 1.0.0

- первая версия библиотеки `YandexMaps`
- добавлен компонент `КартаЯндекса`
- добавлена структура `МеткаКарты`
