# Changelog

## 1.1.5

- добавлена настройка `ApiKeyV3` в `НастройкиYandexMaps` для раздельного хранения ключей v2.1 и v3
- при `ВерсияApi == "3"` компонент использует `ApiKeyV3` с fallback на `ApiKey`
- уточнены диагностические сообщения об отсутствии ключа с указанием версии API

## 1.1.4

- исправлена инициализация Yandex Maps JS API v3: используется `YMapDefaultSchemeLayer`
- добавлена регистрация CDN для пакетов v3 и безопасный fallback с кластеризации на обычные маркеры
- загрузка zoom-control в v3 больше не блокирует отображение карты при ошибке пакета UI

## 1.1.0

- добавлено свойство `ВерсияApi` в компонент `КартаЯндекса` (значения `"2.1"` / `"3"`, по умолчанию `"2.1"`)
- добавлена поддержка Yandex Maps JS API v3: кластеризация, кастомные DOM-маркеры, попап с заголовком и описанием при клике
- v2.1 остаётся без изменений — обратная совместимость сохранена

## 1.0.0

- первая версия библиотеки `YandexMaps`
- добавлен компонент `КартаЯндекса`
- добавлена структура `МеткаКарты`
- добавлены настройки хранения `ApiKey` через `СекретПриложения`
