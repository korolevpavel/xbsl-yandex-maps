# Changelog

## 1.0.3

- добавлены свойства `Высота: Число?` и `Ширина: Число?` в компонент `КартаЯндекса`
- не заданы → компонент растягивается по вертикали / горизонтали
- заданы → компонент фиксируется по указанным размерам
- ⚠️ Breaking change: дефолтная высота изменилась с `420` на растягивание по вертикали
