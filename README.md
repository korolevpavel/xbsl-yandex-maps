# YandexMaps — библиотека для 1С:Предприятие.Элемент

Библиотека добавляет интерактивный компонент [Яндекс Карт](https://yandex.ru/maps-api/) в приложения на платформе **1С:Предприятие.Элемент** в виде переиспользуемого элемента интерфейса.

## Возможности

- отображение меток на карте с заголовком и описанием
- автоматический подбор границ карты по меткам
- кластеризация меток
- явное управление центром и масштабом
- безопасное хранение API-ключа через `СекретПриложения`

## Установка

1. Добавьте библиотеку `korolevpavel / YandexMaps / 1.0.2` в зависимости вашего проекта.
2. Откройте настройки и заполните API-ключ:
    ```xbsl
    НастройкиYandexMaps.СоздатьФормуЗаписи().Открыть()
    ```
3. Ограничьте ключ по домену приложения в [кабинете Яндекс Карт](https://developer.tech.yandex.ru/).

## Свойства компонента `КартаЯндекса`

| Свойство | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Метки` | `Массив<МеткаКарты>` | — | Список меток на карте |
| `АвтоПодобратьГраницы` | `Булево` | `Истина` | Авто-фит viewport по меткам |
| `КластеризоватьМетки` | `Булево` | `Истина` | Группировка близких меток |
| `ЦентрШирота` | `Число` | `null` | Явная широта центра карты |
| `ЦентрДолгота` | `Число` | `null` | Явная долгота центра карты |
| `Масштаб` | `Число` | `null` | Явный масштаб карты |
| `ApiKey` | `Строка` | `null` | Override ключа для нестандартных сценариев |

## Структура `МеткаКарты`

| Поле | Тип | Описание |
|---|---|---|
| `Идентификатор` | `Строка` | Уникальный идентификатор метки |
| `Широта` | `Число` | Широта (latitude) |
| `Долгота` | `Число` | Долгота (longitude) |
| `Заголовок` | `Строка` | Заголовок balloon/hint |
| `Описание` | `Строка` | Текст balloon |

## Рекомендации

- Храните бизнес-данные о локациях в собственных объектах приложения, преобразуйте их в `Массив<МеткаКарты>` в прикладном коде.
- Используйте свойство `ApiKey` компонента только как override. Основной способ хранения — `НастройкиYandexMaps.ApiKey` типа `СекретПриложения`.
- API-ключ участвует в загрузке JS API на клиенте — ограничивайте его по домену в кабинете Яндекс.

## Ограничения v1

- компонент только отображает карту со стандартными balloon/hint
- геокодирование адресов не поддерживается
- выбор координат кликом и встроенный редактор меток не реализованы
