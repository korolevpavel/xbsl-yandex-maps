# Демо-проект `DemoYandexMaps`

Минимальное приложение 1С:Элемент, которое показывает использование библиотеки `korolevpavel::YandexMaps`.

## Что делает демо

- открывает форму `ДемоКарта` через автоинтерфейс
- показывает несколько меток на компоненте `КартаЯндекса`
- дает кнопку для открытия настроек `НастройкиYandexMaps` и заполнения `ApiKey`

## Как запустить

1. Подключите библиотеку `korolevpavel / YandexMaps / 1.0.2` в проекте `DemoYandexMaps`.
2. Откройте форму записи `НастройкиYandexMaps` и заполните `ApiKey`.
3. Запустите приложение и откройте форму `ДемоКарта`.

## Примечание

Если библиотека используется из исходников этого же репозитория, зависимость в `Проект.yaml` демо-проекта должна соответствовать опубликованной или подключенной в среде разработки версии библиотеки.
