## Что это за проект

Библиотека `YandexMaps` для платформы **1С:Предприятие.Элемент** — добавляет интерактивный компонент Яндекс Карт в виде переиспользуемого элемента интерфейса.

- **Язык платформы:** xbsl (1С:Элемент), конфигурация описывается в YAML
- **Сборка:** выполняется инструментами платформы 1С:Элемент, скриптов сборки в репозитории нет
- **Артефакты:** `.xlib` (библиотека), `.xasm` (приложение) — хранятся в `dist/` (в .gitignore)

## Структура репозитория

```
YandexMaps/          # Исходный код библиотеки (единственная отслеживаемая директория)
  Основное/          # Публичное API: компонент КартаЯндекса + структура МеткаКарты
  Настройки/         # Константы: НастройкиYandexMaps с ApiKey типа СекретПриложения
  Служебные/         # Внутренние модули: СервисYandexMaps (серверный, управляет ключом)
  Проект.yaml        # Метаданные библиотеки (версия, вендор: korolevpavel)
  CHANGELOG.md
  README.md
```

`DemoYandexMaps/`, `dist/`, `tools/` — в `.gitignore`, в репозитории не хранятся.

## Архитектура

### Компонент `КартаЯндекса` (`Основное/КартаЯндекса.xbsl`)

Компонент типа `КомпонентИнтерфейса`. Генерирует HTML-документ со встроенным JavaScript, который загружает Yandex Maps JS API и отрисовывает карту с метками.

Свойства компонента:
- `Метки` — `Массив<МеткаКарты>` (основной вход данных)
- `ЦентрШирота`, `ЦентрДолгота`, `Масштаб` — явное управление viewport
- `АвтоПодобратьГраницы` — авто-фит по меткам (по умолчанию `Истина`)
- `КластеризоватьМетки` — кластеризация (по умолчанию `Истина`)
- `ApiKey` — override ключа на уровне инстанса (основной способ — через настройки)

### Структура `МеткаКарты` (`Основное/МеткаКарты.yaml`)

Публичный DTO для передачи меток в компонент. Поля: `Идентификатор`, `Широта`, `Долгота`, `Заголовок`, `Описание`. Имеют JSON-аннотации (`id`, `lat`, `lng`, `title`, `description`) для сериализации в JS.

### Сервис `СервисYandexMaps` (`Служебные/СервисYandexMaps.xbsl`)

Серверный общий модуль. Отвечает за:
- получение `ApiKey` из `НастройкиYandexMaps` с нужным контекстом доступа
- генерацию диагностического сообщения при отсутствии ключа

### Настройки `НастройкиYandexMaps` (`Настройки/НастройкиYandexMaps.yaml`)

Набор констант с доступом только для администраторов. Хранит `ApiKey` типа `СекретПриложения`.

## Принципы библиотеки

- Библиотека **не навязывает модель хранения** локаций — потребитель сам хранит данные и преобразует их в `Массив<МеткаКарты>`
- `ApiKey` через свойство компонента — только для нестандартных сценариев; основное хранение — `НастройкиYandexMaps.ApiKey`
- Ключ участвует в загрузке JS API на клиенте (ограничивать по домену в кабинете Яндекс)

## Версионирование

Версия хранится в `YandexMaps/Проект.yaml`. При выпуске новой версии обновляется `Проект.yaml` и `CHANGELOG.md`.
